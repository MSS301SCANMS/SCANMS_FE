# Sora Skin clothing sample

`sora-caro-shirt.webp` is checked into Git so sample catalog photos work on a fresh
checkout without relying on an image hosting account. It is the blue checked shirt
from the existing SCANMS default catalog, originally sourced from DummyJSON and
hosted at `demo-fashion-v1/products/d-83-1.webp`. It illustrates the sample product;
it is not evidence of actual Sora Skin inventory.

The matching Product Service seed and setup instructions are in
`SCANMS_BE/product-service/SORA_CLOTHING_SEED.md`.

`sora-white-tshirt.png` is an AI-generated sample catalog photograph created with
the built-in ImageGen tool. It is stored locally for portable test data.
Prompt: A plain white cotton crew-neck short-sleeve t-shirt, front view, natural
fabric texture, ghost mannequin silhouette, no person, centered whole garment,
warm white studio background, soft shadow, no logo, text or accessories.
